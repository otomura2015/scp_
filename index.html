Sobre este arquivo

A Fundação SCP é uma organização fictícia dedicada à identificação, contenção e estudo de fenômenos que não podem ser explicados pelos meios convencionais.

Os registros abaixo apresentam versões resumidas dos principais itens catalogados. Consulte o banco de dados para acessar os arquivos individuais.
